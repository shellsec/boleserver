# BoleServer 外观设计

用户确认同时提供「音乐馆」与「播放室」，全部五主题重新设计，整体干净，优先首页、歌单、手机播放页。仅本地修改，禁止提交与推送。

音乐馆：清晰的内容层级、安静底色、规整歌单封面与轻量播放栏。播放室：更大封面、放松的间距及适量封面背景，保留相同操作位置。

五主题保留 emerald/blue/amber/violet/rose ID 兼容旧偏好，展示为青瓷/潮汐/麦芽/暮紫/莓红；各自有独立浅色/深色表面。主色分别 #28736A/#365CB7/#9B681F/#7655A3/#A64D6A。字体采用系统 Segoe UI Variable / PingFang SC / Microsoft YaHei，标题使用明确字重与紧凑字距，不加载远程字体。

以新增有作用域的样式表为主，不修改音源、播放、搜索、歌单或缓存的数据逻辑。外观设置提供两风格按钮，保存到独立 boleserver_visual_style 本地偏好。选项有 aria-pressed，支持键盘焦点、减少动态效果与窄屏安全区。

关于信息：当前维护者 shellsec 与问题入口指向 BoleServer；原作者、仓库来源、许可集中在关于页和 README；保留所有原始版权及许可声明。主内容区不重复运营或维护信息。
