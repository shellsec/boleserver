# 音源订阅与失效恢复

将移动端现有订阅机制适配到 lxserver，发布到 shellsec/lxserver。

- 每个用户（包括公开源作用域）保存一个可清除的订阅地址。
- 兼容移动端 JSON 数组或 {"sources": [...]}，条目为 id/name/url，支持相对地址和 BOM。
- 手动保存并更新；所有候选源失败后自动检查。每首歌最多一次，每个作用域/地址每分钟最多一次；仅内容变化后再试一轮。
- 全部脚本下载、校验成功才替换本地订阅；出错保留旧脚本。保留手动音源、排序、已有启停状态；新订阅源默认启用。
- 自动更新不升级 VM 权限。公开订阅由管理员管理，私有订阅必须匹配已验证用户。
- 每次源解析最多 15 秒，超时继续下一源；保留现有关闭自动切换设置。
- 不加后台定时轮询，与移动端失效时恢复保持一致。

方案：复用现有服务端音源加载和排序切换，新增订阅存储/清单模块与管理 UI。单 JS 定时下载与移动端清单不兼容，因此不采用。
